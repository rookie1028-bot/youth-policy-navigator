# Roadmap

Youth Policy Navigator is moving from a single MVP page toward a reusable open-source pattern for AI-assisted public-service navigation.

## Phase 1 — Maintainer-ready OSS baseline

- [x] Public repository
- [x] README explaining purpose, usage, roadmap, and contribution path
- [x] MIT license
- [x] Contributing guide
- [x] Core tests for profile normalization, scoring, filtering, and markdown export
- [ ] GitHub Pages demo
- [ ] Issue templates

## Phase 2 — Better policy data workflow

- [ ] Define a policy seed JSON schema
- [ ] Add validator for missing official URL, deadline, and next action
- [ ] Add CSV/JSON import
- [ ] Split seed policies into region packs
- [ ] Add stale-deadline warning

## Phase 3 — AI-assisted civic workflow

- [ ] Generate document checklists from selected policies
- [ ] Summarize official notices into plain Korean
- [ ] Export counseling-ready markdown and form-preparation notes
- [ ] Add Codex-assisted PR review for data corrections
- [ ] Create templates for other local policy navigators

## Phase 4 — Community and ecosystem

- [ ] Publish a contribution guide for non-developer policy researchers
- [ ] Create starter issues for city/region packs
- [ ] Document how schools, youth centers, and local creators can fork the app
- [ ] Collect public examples of forks or adaptations
